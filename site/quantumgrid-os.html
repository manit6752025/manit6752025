QuantumGrid OS

Your network. Your rules.

An OpenWrt-based network operating system for Qualcomm routers, first built for the Arcadyan AW1000. It pairs a pinned, reproducible firmware build with a React control centre that talks to real router services.

View on GitHubProject website

What it does

Control centre

Dashboard, Network, Wi-Fi, Gaming, 5G, Security and System views on live router data.

Office networks

Guarded VLAN, DHCP, firewall zone and routed segment tools with rollback.

Enterprise Wi-Fi

WPA2 and WPA3 Enterprise with RADIUS and optional dynamic VLANs.

5G and voice

Quectel RG500Q-EA modem telemetry and an RJ11 phone port integration.

Gaming

SQM and CAKE queue controls plus per-client DSCP marking.

Secure releases

Pinned OpenWrt commits, SHA-256 checksums and build provenance.

Try it

git clone https://github.com/NetCore-Technologies/QuantumGrid-OS.git
cd QuantumGrid-OS
./build.sh

The AW1000 is the only supported profile today, and NSS offload is experimental.
