WiFi Analyzer Pro

See the spectrum. Own your network.

Local-first Wi-Fi visibility and network diagnostics for engineers, IT teams and power users. A Python backend and React dashboard bring wireless observations and practical checks into one place.

View on GitHubProduct website

What it does

Access points

SSID, BSSID, band, channel, signal and advertised security for nearby networks.

Channels

Compare occupancy and congestion across nearby networks.

Diagnostics

Gateway reachability, latency, DNS and packet loss where the host allows.

Trends

Privacy-preserving site history for RSSI, density, latency and loss.

Router agents

Read-only OpenWrt snapshots from enrolled, scoped agents.

Demo mode

Explore the dashboard without Wi-Fi hardware, clearly labelled as sample data.

Try it

bash wifi_analyzer_backend/setup.sh
open http://127.0.0.1:199

WIFI_ANALYZER_DEMO=1 python3 wifi_analyzer_backend/server.py

Only scan networks you own or are authorised to assess.
